# Logos do evento

A capa mostra as marcas do TDC e do REC'n'Play. Enquanto os arquivos oficiais não estão aqui, ela usa uma versão tipográfica.

Para usar os logos oficiais:

1. Salve os arquivos aqui como `tdc.svg` e `recnplay.svg` (PNG também funciona).
2. Em `src/slides/capa/slide.html`, troque cada `<span class="evword …">` pelo `<img class="evlogo" …>` indicado no comentário logo antes dele, e rode `python3 tools/build.py`.
