// GLOSSÁRIOtermos exatamente como usados nos slides
Bounded context
Fronteira onde um modelo de domínio tem significado único.
Contrato do módulo
Facade, DTOs e eventos: a única parte de um módulo visível aos outros.
Port
Contrato definido pelo domínio, na linguagem do negócio.
Adapter
Implementação do port para uma tecnologia ou provedor.
Anti-Corruption Layer (ACL)
Camada que traduz o modelo externo para o modelo do domínio.
Saga
Sequência de passos com compensação para transações distribuídas.
Idempotência
Repetir a mesma operação não produz efeito duplicado.
Structured output
Saída do modelo validada contra um schema: formato como contrato.
Spec-driven development
A spec aprovada é a entrada do agente; código é derivado dela.
AGENTS.md · SKILL.md
Instruções de repositório e pacotes de habilidade lidos pelo agente.
Orquestrador
Agente que decompõe a tarefa e delega a agentes especialistas.
Handoff
Transferência de tarefa entre agentes, com contrato de tamanho.
Context engineering
Escolher o que entra na janela: write · select · compress · isolate.
Harness
Tudo em volta do modelo: ferramentas, guardas, sensores, verificação.
Loop
Ciclo agir → verificar → corrigir até um critério de parada.
Evals
Testes do comportamento do agente sobre casos e critérios definidos.
Budget
Teto de tokens e iterações por tarefa: para o loop sem progresso.
Bulkhead
Compartimentos isolados: a falha de um não contamina os outros.
HITL
Humano no loop: aprovação antes de ação sensível.
MCP
Protocolo aberto que conecta agentes a ferramentas e dados.
A2A · Agent Card
Protocolo agente↔agente; o card descreve skills, endpoint e segurança.
On-behalf-of
Token que permite ao agente agir em nome do usuário, com escopo mínimo.
EMA · ID-JAG
Autorização do MCP gerida pela empresa: o IdP emite a asserção que vira token de acesso.
AI Gateway
Borda única para tráfego de IA: credenciais, políticas, custo, traces.
AgentOps
Operar agentes com métricas de trajetória, contexto, políticas e avaliação.
AI FinOps
Gestão financeira do consumo de IA: visibilidade, controle e apropriação de custo.
Cost-per-success
Tokens gastos divididos pelas tarefas concluídas com sucesso, não pelas tentativas.
